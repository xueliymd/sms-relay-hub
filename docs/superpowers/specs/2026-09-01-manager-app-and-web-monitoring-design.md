# Relay Hub 管理端 App 与网页实时监控设计

## 背景

当前系统已有 Android、Root、iPhone 和脚本采集端，也已有 FastAPI 管理接口与 React 网页管理台。采集 App 1.0.11 已完成双卡修复和在线更新，但仍不包含管理员登录、实时短信、设备状态或平台运行信息。

本设计新增独立原生 Android 管理端 App，并同步完善网页管理台。两端共用后台数据和读取规则；管理端 App 定位为**移动管理客户端**（含经二次确认的写操作，边界见“非目标”一节的 2026-09-12 范围变更记录），网页继续承担完整管理与高风险操作（容器更新、数据库恢复、Root 安装）。

## 目标

1. 新增 Relay Hub 管理端 Android APK。
2. 支持域名、IP 或 IP:端口连接平台。
3. 支持保存一个或多个平台配置并快速切换。
4. 支持管理员账号密码登录和安全自动重连。
5. 支持按设备和 SIM 实时查看完整短信和验证码。
6. 支持查看设备、SIM、API、WebSocket、端口、HTTPS、证书、容器、数据库和版本状态。
7. 网页同步使用相同实时消息和运行状态接口。
8. 管理端故障不得影响采集 App 的短信接收和上传。

1. 管理端 App **可**执行设备写操作（创建、凭据轮换、撤销/恢复/永久删除）与消息写操作
   （已读/未读、单条删除、批量删除、保留清理），以及 SIM 手机号映射的修改与删除。
   约束：每个写操作都必须二次确认；一次性凭据与一次性令牌只在弹窗中显示一次，不落盘、不回显。
2. 管理端 App **可**修改管理员账号。约束：必须校验当前密码，成功后强制重新登录。

4. 管理端 App 不使用 WebView。
5. AccessibilityService 保活属于独立可靠性子项目。
6. 不静默安装 APK、Root 模块或容器更新。

## 总体架构

1. 采集 App：短信广播接收、队列、签名上传、前台服务和自身更新。
2. 管理端 App：原生 Android 移动管理客户端，负责登录、平台切换、实时消息、状态查看，以及经二次确认的写操作（边界见“非目标”一节的范围变更记录）。
3. 网页管理台：保留完整管理能力，增加实时设备监控、运行状态、冲突提示和发布历史。
4. FastAPI：认证、数据、过滤、状态判断和实时事件的唯一事实来源。

网页和 App 不自行推断在线、冲突或 API 地址，统一使用后台结果。

## 管理端 App

### 技术边界

- 独立目录 manager-android。
- Application ID 为 io.smsrelay.manager。
- minSdk 26，Kotlin 原生界面，不使用 WebView。
- HTTP 与 WebSocket 使用 OkHttp。
- 密码和会话使用 Android Keystore AES-GCM 加密保存。
- 使用独立应用 ID 和管理端发布签名。

### 平台配置与登录

每个平台保存本地名称、Base URL、管理员用户名、是否记住密码、加密密码、加密会话、过期时间、最近连接时间和错误分类。

Base URL 可为 https://sms.example.com 或 http://203.0.113.10:39300。保存前移除末尾斜杠，只允许 HTTP/HTTPS，拒绝内嵌账号密码、Fragment 和其他协议。

登录调用 POST /api/v1/admin/login。登录成功后保存用户名、会话和过期时间；只有启用“记住密码”才保存 Keystore 加密密码。启动时优先复用未过期会话；会话失效且存在加密密码时只自动重新登录一次，失败后返回登录页。

继续使用现有 X-Admin-Token 协议，不破坏网页兼容性。删除平台配置时同时删除密码和会话密文。

## 实时消息协议

新增 WebSocket /api/v1/ws/admin/messages。

1. 客户端建立连接。
2. 第一帧发送管理员会话、设备 ID、可选 SIM slot 和最后事件游标。
3. 服务端返回 auth_ok 和 subscribed。
4. 新短信事务提交后，只向匹配订阅发送完整消息事件。
5. 支持 ping/pong。

事件包含完整消息序列化结果和单调递增游标，不包含密钥或管理员凭据。GET /api/v1/admin/messages 增加增量游标参数，重连前先补齐遗漏数据。现有 OTP WebSocket 保持不变，并与管理员完整短信流分离权限。

## 后台接口扩展

### 平台运行状态

扩展 GET /api/v1/admin/runtime，安全返回平台版本、构建时间、服务器时间、公开站点 URL、HTTP/HTTPS/内部端口、HTTPS 状态、证书到期、App/PostgreSQL/Caddy 健康、数据库 backend/fingerprint 和最新 APK/Root/部署包版本。

> **实现现状（2026-09-12 核对）**：已返回平台版本、服务器时间、公开站点 URL、HTTP/HTTPS/内部端口、
> `https_enabled`、Caddy/数据库/App 健康、数据库 backend/fingerprint，以及**最新 APK/Root/部署包版本**
> （`latest_releases`，读发布清单，清单不可读时降级为空对象）。
> **`certificate_expires_at` 恒为 `null`**：443/QUIC 端口映射已移除，TLS 由上游反代（宝塔 nginx）终结，
> 容器内不再持有证书，因此平台无法报告到期时间。保留该字段是为了让客户端能区分"不适用"与"后端漏返回"；
> 判断链路是否加密请用 `https_enabled` + `public_base_url`。
> **构建时间未实现**：当前没有任何环节注入构建时间（`platform_version` 由 `.env` 的 `PLATFORM_VERSION` 提供），
> 需要时应在部署流程里注入一个 `BUILD_TIME` 环境变量，而不是在运行期猜测。

FastAPI 不挂载 Docker socket；容器状态只来自安全健康摘要或部署时注入数据。

### 设备状态与冲突

设备读取结果增加 online、client_instance_id、client_version、client_mode、duplicate_collection_warning 和 credential_reuse_warning。在线状态按最后心跳或上报时间计算，不能把 active=true 当作实时在线。

客户端上报可选稳定实例 ID 和版本。后台针对同一凭据多实例、APK/Root 重复采集、同一 device ID 多来源和 SIM 多候选产生只读告警。第一阶段不自动停用设备或丢弃短信。

## 网页管理台完善

网页保留现有设备创建、凭据轮换、撤销、恢复、永久删除、SIM 编辑、消息已读和删除，并增加：

1. 按设备和 SIM 订阅完整短信 WebSocket。
2. 实时连接状态、断线提示和增量补偿。
3. 真实在线、最后上报、实例 ID、版本和冲突告警。
4. 域名、端口、HTTPS、证书、容器、数据库和版本面板。
5. API 与 WebSocket 地址复制和测试。
6. APK、Root 和部署包发布历史只读展示。

发布、更新和回滚执行器只存在于网页和服务器维护流程，不加入管理端 App。本子项目提供发布历史和状态读取；容器备份、镜像切换和失败回滚执行器另立设计与计划。

## 安全与错误处理

- 登录失败统一显示用户名或密码错误。
- 自动登录失败后停止自动尝试。
- App 日志不得记录密码、管理员令牌、设备密钥或完整短信正文。
- 网页和 App 使用稳定错误码，不显示后端堆栈。
- HTTP 可连接但明确标记未加密；证书错误默认阻止登录。
- 不提供忽略全部 TLS 错误的全局开关。
- 切换平台时关闭旧 WebSocket 并清空内存短信列表。
